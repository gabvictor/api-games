👥 Equipe e conceito

Equipe: Gabriel Victor, Matheus Salomão e Lucas Lima.

Conceito: catálogo de jogos de diversas plataformas, separados por categoria (cada plataforma — PS1, PS2, Xbox 360, Switch etc. — é uma categoria). Cada pessoa pode criar um perfil e salvar ou excluir os jogos que quer.

Linguagem: Python (Flask) · Banco: SQLite · Site: HTML, CSS e JavaScript · Empacotamento: Docker.

⚙️ Como os dados foram tratados

  1. Download: os 5 primeiros arquivos da tabela foram baixados do Zenodo (repositório científico). Não usamos o arquivo de capturas de tela (2,8 GB).
  2. Filtro: o script etl.py mantém apenas as plataformas pedidas: PlayStation 1 a 5 (mais PSP e Vita), Xbox (original, 360, One, Series X|S) e todos os consoles Nintendo.
  3. Limpeza: remove jogos repetidos, converte as datas (do formato Unix para AAAA-MM-DD), troca valores “Missing”/“nan” por vazio e traduz os nomes dos gêneros para português.
  4. Imagens: ferramentas/baixar_capas.py baixa só nome, ano e URL da imagem do dataset RAWG (leitura parcial de um arquivo de 1 GB) e ferramentas/casar_capas.py liga cada jogo do catálogo à imagem pelo nome e ano, gerando dataset/capas.csv. Cerca de metade dos jogos ganhou imagem.
  5. Banco: grava tudo em um banco SQLite (catalogo_inicial.db), que é o que a API consulta — por isso funciona 100% offline.

Tabelas: jogos, categorias, generos, jogo_categoria, jogo_genero, perfis, perfil_jogos.

🖼️ Imagens e ícones dos jogos

Ícones: o dataset do IGDB não inclui imagens de capa. Por isso cada jogo tem uma “capa” gerada pelo próprio site: a cor e o ícone da marca (PlayStation, Xbox, Nintendo) e um emoji do gênero. Ela aparece quando o jogo não tem imagem ou quando não há internet. Os ícones das marcas são desenhos simples feitos para este trabalho, não os logotipos oficiais.

⚠️ Limitações

  • O IGDB é uma base colaborativa: consoles muito antigos têm poucos jogos cadastrados (ex.: Game Boy) e alguns nem aparecem (Virtual Boy).
  • Alguns jogos não têm descrição, nota ou ano — nesses casos o site mostra “—” ou “desconhecido”.
  • As descrições dos jogos estão em inglês, como no dataset original.
  • O dataset foi coletado em 2023/2024; lançamentos posteriores não aparecem.
