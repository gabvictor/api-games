Documentação da API

API REST em Python (Flask) do Catálogo de Jogos: jogos de várias plataformas separados por categoria, com perfis para salvar favoritos. Tudo em JSON; erros vêm como {"erro": "mensagem"}. Abra qualquer endpoint abaixo e use Testar para chamar a API de verdade.

🌐 Endereço base

Sem autenticação e sem prefixo (/cat/..., /perf/...).

🧭 Como a API está organizada

/cat = categorias (plataformas) e seus jogos · /perf = perfis e jogos salvos. Um jogo pode estar em várias categorias.

📋 Códigos de resposta

200 OK
201 criado (cabeçalho Location)
204 excluído, sem corpo
400 dados inválidos · 404 não encontrado
